# Werner–PSO Automated Magnetic Anomaly Inversion

This repository contains the Python implementation of an automated magnetic anomaly inversion workflow developed for the manuscript:

**Mashaka, G.P. (2026). Automated Magnetic Anomaly Inversion Using Werner Deconvolution and Particle Swarm Optimization: A Reproducible Workflow for Airborne Geophysical Data. Computers & Geosciences, submitted.**

The workflow integrates magnetic anomaly detection, profile extraction, Werner-based initialization, and Particle Swarm Optimization (PSO)-based inversion to support reproducible interpretation of airborne magnetic datasets.

---

## Purpose of the Repository

The purpose of this repository is to provide open-source code supporting the reproducibility of the manuscript.

The scripts are designed to help users:

- load magnetic raster or grid data;
- detect significant magnetic anomaly peaks;
- extract magnetic profiles across selected anomalies;
- estimate initial source parameters using a simplified Werner-based approach;
- refine source parameters using global optimization;
- summarize inversion results, including source position, depth, amplitude, and RMSE;
- generate reproducible outputs such as CSV summaries and profile/peak plots.

This repository is provided to satisfy the **Computer Code Availability** requirements for *Computers & Geosciences*.

## Main Scripts

### `src/appendix_a_werner_pso.py`

Provides a compact general-purpose implementation of the main workflow, including:

- raster loading;
- magnetic peak detection;
- profile extraction;
- simplified Werner-based initialization;
- forward modelling;
- global optimization;
- RMSE-based model evaluation.

### `src/main_inversion_workflow.py`

Provides a simplified reproducible version of the main Werner–PSO workflow. This script demonstrates the core computational steps in a transparent and easy-to-run format.

### `src/peak_detection_profile_extraction.py`

Contains routines for detecting magnetic anomaly peaks and extracting horizontal or vertical magnetic profiles from raster/grid inputs. The script also supports saving peak coordinates, selected profiles, and figure outputs.

### `examples/run_quick_test.py`

Provides a minimal quick-test example showing how to run the workflow using example input data.

## Quick Test

To run the quick-test example:

```bash
python examples/run_quick_test.py
```

The quick test demonstrates the main workflow steps:

1. Load example magnetic anomaly data.
2. Detect significant anomaly peaks.
3. Extract magnetic profiles across selected peaks.
4. Estimate initial source parameters using a Werner-style initialization.
5. Refine source parameters using global optimization.
6. Save inversion results and example outputs.

Generated outputs are saved in the `outputs/` directory.

---

## Input Data

The workflow can be adapted for:

- raster magnetic grids, such as `.tif` or `.ers` files;
- CSV or XYZ-style magnetic anomaly data;
- extracted magnetic profiles.

Input data should be preprocessed before inversion where appropriate. Typical preprocessing may include despiking, leveling, gridding, removal of regional trends, or reduction-to-pole/reduction-to-equator processing depending on the dataset and study objectives.

The example file `examples/aoi_magnetic_anomalies3.csv` is included as a small test dataset for demonstrating the workflow.

---

## Outputs

The workflow can generate the following outputs:

- detected anomaly peak tables;
- extracted magnetic profile tables;
- inversion result summaries;
- estimated source position `x0`;
- estimated depth `z0`;
- estimated anomaly amplitude `A`;
- root mean square error `RMSE`;
- optional peak maps and profile plots.

Example outputs are written to the `outputs/` folder.

## General Workflow

```text
Input magnetic data
        ↓
Raster or grid loading
        ↓
Anomaly peak detection
        ↓
Profile extraction
        ↓
Werner-based initialization
        ↓
Forward modelling
        ↓
PSO-style/global optimization
        ↓
Model fit assessment using RMSE
        ↓
CSV and plot outputs
```

## Reproducibility Notes

The scripts in this repository are provided as individual source files, not as a compressed archive, in accordance with the open-source code requirements of *Computers & Geosciences*.

The quick-test example is intended to verify that the main computational workflow can be executed by third-party users. Study-specific preprocessing, visualization, or large raster datasets may need to be adapted depending on local file paths, data size, and data licensing conditions.
